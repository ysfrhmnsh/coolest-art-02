# Dragon Over the Burning Mountain — coolest-art-01 (v2 entry)

Entry for the make.fun bounty coolest-art-01: a great dragon silhouetted
against a blood moon, wings spread, crossing the sky above an erupting
volcano. Lava streams run down the cone, embers rise into the red sky, and
a river of fire cuts the foreground. Drawn procedurally by `main.py`
(Python 3.13, standard library only) — no vendored image.
